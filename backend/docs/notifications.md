# إشعارات البلاغات

يتطلب التخزين ترحيل `006_notifications.sql` وصلاحيات الجداول المرفقة في سكربت الترحيل المحلي. يبقى هذا الترحيل ضمن الدفعة المؤجلة مع `005`؛ لا تطبق الاختبارات ترحيلات تلقائيًا. بدون `006` تفشل عمليات إنشاء البلاغات وتغييرات الإسناد والحل وإعادة الفتح في الخادم المشغل مع الإشعارات، وتُلغى المعاملة كاملة. يجب تطبيق الدفعة قبل استخدام هذه العمليات عبر الخادم الجديد.

تُسجل الإشعارات مع حدث البلاغ داخل نفس المعاملة. معرف حدث النشاط هو مفتاح منع التكرار. يتلقى البلاغ الجديد المهندسون والمديرون النشطون، والإسناد المهندس المسند إليه، والحل مالك البلاغ والمديرون، وإعادة الفتح المهندس المسند والمديرون. تُستبعد الحسابات غير النشطة، ولا تُستبعد الحسابات بسبب عدم التوفر المؤقت. البلاغ اليدوي بلا مالك حساب؛ يتلقى المديرون إشعار حله. لا تتضمن رسائل الإشعارات الملاحظات الداخلية أو نص الحل.

كل المسارات تعتمد حساب الجلسة حصريًا، بما في ذلك المدير:

| المسار | الوظيفة |
| --- | --- |
| `GET /api/notifications` | السجل مع `before` و`limit` من 1 إلى 100 و`unreadOnly=true/false` |
| `GET /api/notifications/state?since=0` | الإصدار وعدد غير المقروء و`changed` و`pollAfterMs` |
| `GET /api/notifications/unread-count` | الإصدار وعدد غير المقروء |
| `PATCH /api/notifications/:id/read` | قراءة إشعار الحساب فقط؛ جسم فارغ |
| `POST /api/notifications/read-all` | قراءة جميع إشعارات الحساب؛ جسم فارغ |
| `GET /api/notifications/stream` | SSE مصادق عليه بملف تعريف ارتباط الجلسة |

الإصدارات سلاسل أرقام صحيحة للحفاظ على دقة BIGINT. تُقفل إصدارات الحسابات أثناء الكتابة لضمان ترتيب الاعتماد. SSE يرسل `ready` ثم `refresh` عند التغيير مع رقم الإصدار ومعرف الحدث. عند الاتصال أو إعادة الاتصال يجب تحديث السجل من REST؛ `Last-Event-ID` اختياري، ولا توضع الرموز في الرابط أو تخزين المتصفح. الأحداث لا تنقل نصوص الإشعارات نفسها. يُعاد فحص الجلسة دوريًا ويُنهي `session-ended` الاتصال عند فقد الصلاحية. الحد ثلاثة اتصالات لكل حساب في العملية الواحدة. عند `refresh-error` أو تعذر SSE يمكن استخدام `/state` كل 15 ثانية ثم تحديث السجل والعدد؛ التحديث الدوري يعمل بين عدة عمليات خادم لأنه يستند إلى MySQL. إعداد الوكيل يجب أن يسمح بالبث دون تخزين مؤقت. الأصوات مسؤولية الواجهة فقط.

الاختبارات المعزولة ضمن `npm test`. الاختبارات الحية: `npm run test:integration:notifications`؛ تفشل برسالة واضحة إذا لم تطبق `006` وصلاحياته، ولا يُعتبر ذلك نجاحًا أو تجاوزًا للاختبارات.
